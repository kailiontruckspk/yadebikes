YAD website
1. Upload everything inside this folder to your hosting (public_html). index.html must be at the top level.
2. Free option: drag this folder onto https://app.netlify.com/drop
3. ALL products, prices, WhatsApp number and social links are in js/data.js.
4. GOOGLE SEARCH CONSOLE: every html file has a DRAFT meta tag named google-site-verification. Replace DRAFT-PASTE-YOUR-SEARCH-CONSOLE-VERIFICATION-CODE-HERE with your real code in all html files (find and replace), upload, then click Verify. After that submit https://www.yadebikes.com/sitemap.xml in Search Console.
5. Product pages open in product.html?id=<model id>.
